# Los-Angeles-Crime-Analytics
An interactive Power BI dashboard analyzing Los Angeles crime trends, locations, weapon usage, and victim demographics using Power BI, Power Query, and DAX.

## Objectives
- Analyse reported crime trends across years and times.
- Compare crime records across geographical areas.
- Explore crime descriptions and weapon-recorded cases.
- Examine victim demographics and case-status distributions.
- Build an interactive dashboard using slicers and navigation buttons.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX

## Dashboard Features
- Crime records by time and year
- Case-status analysis
- Area-wise crime comparison
- Yearly treemap visualization
- Interactive filters for year, month, day, victim gender, area, and case status

## Key Learning Outcomes
- Data preparation and transformation
- Dashboard design
- Interactive data exploration
- Communicating analytical findings

Crime Data from 2020 to June 2024 — Los Angeles Open Data. Please add the original dataset source URL and review its licence before redistributing any data.

This project explores recorded crime incidents. Reported counts do not necessarily represent actual crime rates or establish the causes of crime.
